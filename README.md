# درب الساكورا 桜の道

برنامج شخصي لتعلم قراءة وكتابة الهيراغانا والكاتاكانا، مبني على كلمات أعرفها بالسمع، مع تمارين كلام وترديد.

- الشجرة ثلاثية الأبعاد: three.js
- ترتيب ضربات الحروف: [KanjiVG](https://kanjivg.tagaini.net) © Ulrich Apel، رخصة CC BY-SA 3.0
- يُفتح في Chrome على أندرويد، ويُثبَّت من القائمة ← «إضافة إلى الشاشة الرئيسية».
